## When to use
- A bug was fixed or analyzed deeply enough to extract a prevention rule.

## Patch contents
- problem
- root cause
- solution
- prevention
- tags
- affected files

## Rules
- Use evidence, not vague retrospectives.
- Prevention guidance must be specific enough to improve future work.
