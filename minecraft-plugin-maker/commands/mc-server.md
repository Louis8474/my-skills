# Minecraft サーバー起動 & テスト

Paperサーバーを起動し、プラグインをテストします。

## 前提条件チェック

1. `run/`ディレクトリが存在するか確認
2. サーバーが既に起動しているか確認
3. `target/`にjarファイルが存在するか確認

## ワークフロー

### ステップ1: ビルド確認

```
ビルド状況を確認中...
```

- `scripts/build.sh`を実行（存在する場合）
- `target/`にjarファイルがあるか確認
- ない場合: `mvn package`を実行

### ステップ2: サーバーステータス確認

```
サーバーステータス: [起動中/停止中]
```

- 起動中の場合: スキップ
- 停止中の場合: ステップ3へ

### ステップ3: サーバー起動

```
サーバーを起動中...（バックグラウンド）
```

- `run/`ディレクトリでPaperサーバーを起動
- ポート25565で待ち受け
- ログを監視して起動完了を確認

### ステップ4: RCON確認（開発用）

```
RCON設定を確認中...
```

- `run/server.properties`のRCON設定を確認
- 必要に応じてRCONを有効化

### ステップ5: 接続情報表示

```
=== 接続情報 ===

アドレス: localhost:25565
RCON: localhost:25575 (password: plugin-dev)

Minecraftから接続してください。
```

## サーバー管理コマンド

```
利用可能なコマンド:
- /server start  : サーバーを起動
- /server stop   : サーバーを停止
- /server restart : サーバーを再起動
- /server logs    : ログを表示
- /server reload  : プラグインをリロード
```

## クリーンアップ

テスト完了後：
- サーバーを停止
- 必要に応じてlogsをクリア

## 出力

- サーバー起動状態
- 接続情報
- RCON情報（開発用）
