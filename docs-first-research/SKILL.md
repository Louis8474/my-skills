## When to use
- A library, framework, API, or external tool must be used correctly.

## Procedure
1. Confirm which exact library or API needs documentation.
2. Prefer Context7 when available.
3. Fetch only the relevant source pages.
4. Summarize only the parts that change the implementation.

## Rules
- Avoid broad web exploration without a clear target.
- Bring back task-specific guidance, not generic tutorials.
